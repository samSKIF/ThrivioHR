High-impact nits to fix

Split Nx passthrough only once
Right now you split(' -- '), which will rejoin any extra -- in Jest args. Use a single split at the first passthrough:

const cut = currentTestWeb.indexOf(' -- ');
const nxPart = currentTestWeb.slice(0, cut);
let jestArgs = currentTestWeb.slice(cut + 4);


This avoids duplicating/reshuffling when Jest args themselves contain --.

Support let/var config objects
Your coverage injector only matches const. Allow all:

const configMatches = [...content.matchAll(/(?:const|let|var)\s+(\w+)\s*=\s*\{/g)];


Drizzle scan should include .tsx
Ripgrep path only looks at --type ts. Include tsx too:

With rg: rg -l "pgTable|mysqlTable|sqliteTable" -t ts -t tsx .

Fallback find: include -name "*.tsx" in the expression.

Safer Nx --config replacement
If an existing --config is quoted or has an equals form, your regex may miss it. Make it more forgiving:

jestArgs = jestArgs.replace(/--config(?:=|\s+)(["']?)[^\s"']+\1/, '--config apps/web/jest.config.ts');


Verify coverage injected into the right object

const ok = targetVar && content.indexOf('collectCoverage') > content.indexOf(`const ${targetVar} = {`);
